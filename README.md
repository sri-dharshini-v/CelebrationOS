CelebrationOS 🎉

AI-Powered Celebration & Event Planner

CelebrationOS helps users plan birthdays, weddings, and other celebrations with AI-generated event plans based on their budget, guest count, event date, and preferences.

✨ Features

- 🤖 AI-Powered Event Planning — Generate personalized celebration plans using AI.
- 💬 AI Assistant — Get assistance with event-planning questions and decisions.
- 🌐 Multilingual Support — Supports multiple languages for a more accessible planning experience.
- 🎯 Quick Plan & Guided Planner — Choose a planning approach that suits your needs.
- 💰 Budget Planning & Visualization — Organize event expenses and monitor the budget.
- 📅 Event Timelines & Checklists — Keep track of important tasks and deadlines.
- ⚡ Shock Engine — Preview how a plan changes when the budget, guest count, or event date changes.
- ↩️ Safe Undo — Undo supported changes while protecting paid, completed, and important commitments.
- 📚 Version History — Track previous versions of saved event plans.
- 🗂️ History Management — Control history tracking and selectively delete eligible historical revisions.
- 🔒 Protected Commitments & Rituals — Help preserve paid items, completed tasks, and important cultural rituals when plans change.
- 💾 Saved Plans & Plan Management — Save, view, and manage event plans.
- ✅ Plan Validation — Validate plan data, budget calculations, and planning constraints.
- 🏷️ Vendor Recommendations — Help users explore suitable vendors for their events.

🛠️ Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Generative AI: Google Gemini API
- Configuration: Environment variables for server-side settings

🔐 Security

- The Gemini API key is configured on the server side using environment variables.
- Secret keys and environment files should not be committed to the public repository.
- Users should verify sharing permissions before sharing saved plans or other information.

🎯 Project Goal

CelebrationOS aims to make event planning easier, more flexible, and more accessible by combining AI-assisted planning, budget management, change previews, revision history, and support for diverse cultural traditions.
Developed for Google PromptWars Virtual — Challenge 5: Celebration & Event Planner.
